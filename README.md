# Vasthra-Online-Fashion-Store
A fully responsive e-commerce website for sarees and ethnic wear, built with HTML, CSS, JavaScript, and Firebase. The project includes full shopping features such as cart, wishlist, user authentication, admin dashboard, product uploads, and more.

✨ Features
------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
  👗 Customer Features
  
     1. Browse products with images, prices, and details
     2. Add items to Cart
     3. Add/remove items from Wishlist
     4. Product detail page with large preview
     5. User login / registration with Firebase Auth
     6. Profile page with user data
     7. Checkout page with order details
     8. Fully responsive UI (mobile-friendly)
   🛍 Admin Features
   
     1. Secure admin login
     2. Upload products with:
     3. Product name
     4. Price
     5. Description
     6. Local image upload
     7. View all products
     8. Delete products
     9. Manage user orders
     10. Manage user verification (if enabled)

  ⭐ Core Technologies

| Feature            | Technology                                |
| -------------      | ----------------------------------------- |
| Hosting            | Firebase Hosting / Local                  |
| Database           | Firebase Firestore                        |
| Storage            | Local image storage (no Firebase Storage) |
| Auth               | Firebase Authentication                   |
| Frontend           | HTML, CSS, JavaScript                     |
| Admin Panel        | Vanilla JS + Firebase                     |
| Cart/Wishlist      | LocalStorage                              |
